§ 01 — Executive Summary

What we found, in one paragraph

Hotel Luxuria Grand has done the engineering work — clean Next.js build on Vercel, HTTPS with HSTS preload, 54 ms TTFB, valid sitemap, complete alt text on every image. What it has not done is the distribution work: it is essentially invisible on Booking.com, MakeMyTrip, and the "best hotels in Silchar" lists where travellers begin their journey. The schema markup is present but minimal. The /book and /offers pages are thin. And the same Open Graph card ships on every page. Fix those — and seed half a dozen authoritative local citations — and this site can comfortably out-rank the older incumbents in the Barak Valley.

Three things to fix first

1. Claim and complete Google Business Profile. List on Booking.com, MakeMyTrip, Agoda. This is your largest off-site leak — the property currently appears in zero third-party "best of Silchar" aggregations.

2. Enrich Hotel schema. Add geo, aggregateRating, amenityFeature, hasMap, and sameAs for social profiles. Add LodgingBusiness + per-room Product/Offer markup. This alone can earn rich-result eligibility in SERPs.

3. Build out the /book and /offers pages. Currently 93 and 159 words respectively, with /book carrying zero headings. These are the conversion pages — they need to be substantial.

"The site is built well. It just isn't found well."
§ 02 — Technical SEO

Foundations

This is the strongest dimension. The site runs on Next.js behind Vercel's edge network with appropriate security headers, valid sitemap, and well-handled redirects. A handful of small inconsistencies remain.

✓ Pass
HTTPS, HSTS preload, and secure headers
Server returns Strict-Transport-Security: max-age=31536000; includeSubDomains; preload, plus X-Content-Type-Options: nosniff, X-Frame-Options: DENY, and a sensible Permissions-Policy. Best-in-class.
✓ Pass
Non-www → www redirect (301, single hop)
hotelluxuriagrand.com correctly issues a 301 to https://www.hotelluxuriagrand.com/. No redirect chains observed.
✓ Pass
robots.txt and sitemap.xml are valid
robots.txt allows all crawlers, blocks only /private/, and points to the sitemap. sitemap.xml is a well-formed urlset with all 13 site pages and ISO lastmod timestamps.
Low
Canonical URL is inconsistent with internal linking
The homepage canonical is https://www.hotelluxuriagrand.com (no trailing slash), but every internal navigation link points to / and the page itself serves from /. Pick one form and use it everywhere. Recommended: https://www.hotelluxuriagrand.com/.
Low
No <meta name="robots"> directives
Pages default to index, follow, which is fine. Add an explicit <meta name="robots" content="index, follow, max-image-preview:large"> to encourage Google to use large images in SERP previews — important for hotel imagery.
Low
Custom 404 page returns 36 KB and HTTP 404
A missing URL like /sitemap_index.xml returns a styled 404 page weighing ~36 KB. The HTTP status is correct, but the page is heavier than necessary. A leaner 404 (under 10 KB, with helpful navigation back to /rooms, /offers, /book) is cheaper and converts lost visitors better.
Low
Deprecated meta keywords tag is present
No SEO value (Google has ignored this tag since 2009), but harmless. Consider removing for cleaner head and to avoid signalling outdated practices to auditors.

§ 04 — Structured Data

Schema markup

A single Hotel JSON-LD block ships on every page. It is valid and covers the basics — name, address, telephone, price range, star rating. It is also conspicuously missing the half-dozen properties that earn rich results.

What is there

// /  (homepage and every other page)

  "@context": "https://schema.org",
  "@type": "Hotel",
  "name": "Hotel Luxuria Grand",
  "description": "An upscale hotel in Silchar, Assam...",
  "image": "https://.../og_image.webp",
  "url": "https://www.hotelluxuriagrand.com",
  "telephone": "+919181043994",
  "priceRange": "₹2200-₹6500",

  "starRating": { "@type": "Rating", "ratingValue": "4" },
  "checkinTime": "12:00",
  "checkoutTime": "11:00"

What is missing

Critical
No geo coordinates
For a hotel, latitude/longitude is among the strongest local-SEO signals. Add "geo": { "@type": "GeoCoordinates", "latitude": 24.802, "longitude": 92.798 } (use your actual address coordinates).
High
No aggregateRating or review
The footer links to Google reviews but the schema doesn't surface them. Once you have 5+ reviews on GBP, mirror the aggregate (rating + reviewCount) into your Hotel schema. This unlocks star-rating snippets in Google SERPs.
High
No amenityFeature array
List every amenity (Wi-Fi, parking, restaurant, banquet hall, room service, AC, elevator, etc.) as LocationFeatureSpecification entries. This is what Google uses to match queries like "hotel in Silchar with banquet hall".
High
No sameAs linking to social/business profiles
Tell Google these are the same entity: sameAs: ["https://www.instagram.com/luxuria_grand/", "https://www.facebook.com/...", "https://g.co/kgs/your-knowledge-panel-id"]. This is how knowledge panels merge.
Medium
No per-room Product or Offer markup
On /rooms, each of the seven suite categories should ship as a Product with offers (price, currency, availability). Currently the suite list is invisible to structured-data crawlers.
Medium
No Restaurant schema for Anaaya's / Café Cove
Add separate Restaurant blocks for each F&B outlet with menu URL, servesCuisine, priceRange, and opening hours. This drives visibility for "restaurants in Silchar" queries independent of hotel queries.
Medium
No BreadcrumbList
Add a breadcrumb schema to every non-homepage page. Earns breadcrumb display in SERPs in place of raw URL.
Medium
No FAQPage markup
Add an FAQ section to /about or /contact answering: check-in/out times, parking, distance to NIT Silchar, distance to airport, pet policy, kid policy, banquet capacity. Mark up with FAQPage schema to earn featured-snippet eligibility.
Low
Single image instead of an array
Google's hotel rich results prefer multiple images. Change image to an array of 4–6 high-quality photos (exterior, lobby, suite, dining, banquet, pool/gym if applicable).

Medium
Hero image is requested at 4K width
The homepage hero image is fetched at w=3840&q=75. For most users on mobile and laptop screens, this is 2–3× more pixels than displayed. Use next/image sizes attribute to match viewport — meaningful LCP improvement on mobile.
Medium
No <link rel="preload"> for the hero image
The LCP element on the homepage is the hero image. Preloading it (or using next/image priority prop) shaves 200–500 ms off LCP on slow connections — meaningful for Indian mobile traffic.
Low
No font preconnect
If Google Fonts are in use, add <link rel="preconnect" href="https://fonts.googleapis.com"> and <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin> in <head>.
Low
HTML carries Cache-Control: max-age=0, must-revalidate
This is appropriate for SSR/ISR'd Next.js pages and is mitigated by Vercel's edge cache. Keep as-is unless you move to a different host.

Note: Lab-grade Core Web Vitals (LCP / INP / CLS) cannot be measured without a real browser. The TTFB and payload data above are strongly positive predictors; we recommend running PageSpeed Insights and CrUX on production to confirm.

§ 06 — Local SEO

The Silchar problem

For a hotel, local SEO is SEO. This is where Hotel Luxuria Grand is weakest. NAP information is consistent on-site, but the property is barely visible on the channels travellers actually use to find Silchar accommodation.

✓ Pass
NAP consistency on the website
Name, address, and phone are identical across the JSON-LD schema, footer, and /contact page. Good hygiene.
✓ Pass
Strong local-intent keyword targeting
Meta keywords and on-page copy target hotels in Silchar, luxury hotel Silchar, Silchar wedding venue, banquet hall Silchar, hotel near NIT Silchar. The "near NIT Silchar" targeting is particularly smart — parent traffic is a real and underserved segment.
Critical
Invisible on third-party "best hotels in Silchar" lists
In our search across Booking.com (22 hotels listed), Timbu.in (18 hotels), and ResortsNearMe (multiple Silchar entries), Hotel Luxuria Grand does not appear in any aggregation. Competitors like Borail View Regency, Hotel Cachar Club, Hotel Sudakshina, and The Bishal Hotels each appear on multiple listings. This is the single biggest acquisition gap.
Critical
Google Business Profile linkage not surfaced in schema
The footer links to a Google reviews search URL (suggesting a GBP exists), but neither the URL nor a CID is referenced in sameAs or hasMap. If a GBP exists, link it; if not, claim and verify one — it's free and is the single highest-ROI local-SEO action.
High
No listings on OTAs
No visibility on Booking.com, MakeMyTrip, Agoda, Goibibo, or Yatra. Even if direct bookings are preferred, OTAs drive brand-name search volume and provide critical backlinks. List the property on Booking.com and MakeMyTrip at minimum — set rates with parity to direct.
High
No directory citations
Submit consistent NAP to: Justdial, Sulekha, TripAdvisor, India.com, IndiaMART (relevant for B2B/wedding inquiries), and the Assam Tourism directory. Each citation reinforces local relevance.
Medium
Only one verified social profile linked
Instagram (@luxuria_grand) and WhatsApp are linked; footer references Facebook and LinkedIn icons but verifying actual profile URLs is required. Active Facebook and LinkedIn business pages provide additional citation signals.
Medium
No location landing pages for sub-queries
High-intent long-tails like "hotel near Silchar airport", "hotel near NIT Silchar", "wedding venue Silchar with parking" can be captured with dedicated thin landing pages or anchor sections on /events and /contact. The keyword meta already targets these — the on-page content does not.

§ 08 — Off-Page & Backlinks

Authority signals

Authoritative backlink data requires a paid tool (Ahrefs / Semrush) which we cannot query here. From qualitative signals, the property's external authority is in early-stage condition.

What we can see:

The domain does not appear in our search index for "best luxury hotels in Silchar Assam" — top results return six different competitor properties. The property does not show up in OTA aggregations, tourism directories, or "things to do" content. There is no visible press coverage, blogger reviews, or wedding-venue review aggregation. The Instagram account exists, but visibility there does not translate to backlink authority.

Recommendations:

Run an actual backlink audit via Ahrefs Free Site Explorer or Moz Link Explorer to establish baseline. Then pursue, in priority order: OTA listings (Booking, MMT, Agoda — high-DA backlinks), Assam Tourism + Cachar district listings, regional wedding-vendor directories (WedMeGood, ShaadiSaga), university partner pages (NIT Silchar parent-hospitality resources), and press releases in regional outlets at the time of any new launch (banquet expansion, restaurant openings, packages).

§ 10 — Methodology

How we audited

Eleven URLs from the sitemap were fetched and parsed for title, meta description, canonical, robots directives, Open Graph, Twitter card, hreflang, heading hierarchy, image alt coverage, internal link inventory, JSON-LD blocks, and visible word count. HTTP headers were inspected on www, non-www, and HTTP variants to verify redirect behaviour and security posture. robots.txt and sitemap.xml were validated. Performance was measured via cold-cache curl timings to TTFB and total response. Competitive positioning was assessed via semantic search across Booking.com, Timbu.in, and ResortsNearMe; backlink data was qualitative due to absence of paid-tool access.

What this audit could not do: Lab-grade Core Web Vitals (would need Lighthouse on a real browser), full backlink audit (would need Ahrefs / Semrush), mobile UX walkthrough (would need a device emulator), keyword rank tracking (would need a rank-tracking subscription), or GSC console data (would need owner access to Search Console).
