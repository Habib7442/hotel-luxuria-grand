## 1. Project Overview

Hotel Luxuria Grand is Silchar's premier hotel — rated Excellent 4.5/5 — located on NIT Road, Cachar District, Assam. The website must communicate this property as the most desirable, most glamorous destination in the entire Barak Valley. The design direction is **Bold Tropical Luxury** — vibrant, warm, opulent, and deeply inviting. Think the Havanza reference image provided: rich editorial layouts, postcard-style photography, script + serif typography, and a palette that feels sun-soaked and festive rather than cold and corporate.

**This is NOT a dark website.** Everything should feel bright, warm, alive, and celebratory.

## 5. Design Direction

### 5.1 Overall Aesthetic
**Tropical Editorial Luxury** — the same feeling as the reference Havanza moodboard: rich warm creams, vibrant accent colors, postcard-style polaroid photography, generous serif display type, handwritten script accents, and real photography showcasing the hotel.

This aesthetic is:
- Bright, never dark
- Warm, never cold
- Rich, never flat
- Celebratory, never corporate

### 5.2 Color Palette

| Role | Color Name | Hex | Usage |
|---|---|---|---|
| **Base / Background** | Warm Cream | `#FFF8EF` | Page backgrounds, cards |
| **Deep Warm Neutral** | Tobacco Brown | `#3D2B1F` | Navigation bg, footer bg, text headings |
| **Primary Accent** | Marigold Orange | `#E8701A` | CTAs, highlights, borders, icon accents |
| **Secondary Accent** | Teal Pool | `#1A8C8C` | Hover states, section dividers, badges |
| **Tropical Pop** | Sunflower Yellow | `#F5C518` | Tags, labels, highlight chips |
| **Botanical Green** | Palm Leaf | `#3B6E4A` | Supporting accents, nature-themed sections |
| **Text Primary** | Espresso | `#1C1007` | Body copy |
| **Text Secondary** | Warm Taupe | `#7A614E` | Subheadings, captions |
| **White** | Pure | `#FFFFFF` | Card fills, overlays |

**Dominant feel:** Cream/Tobacco backgrounds with Marigold and Teal as the hero accent duo. Never use cold grays or blue-whites.

### 5.3 Typography

#### Display / Hero Font
**Playfair Display** (Google Fonts, free)  
— Used for major headings, section titles, and any text meant to feel grand and editorial  
— Weight: 700 italic for headlines, 400 italic for subheadings  
— Feels: luxurious, classical, editorial  

#### Script / Accent Font
**Cormorant Upright** or **DM Serif Display** (italic)  
— Used for subheadings like *"Rich & Cozy"*, *"Serenity & Bliss"*, section taglines, category labels  
— This is the "handwritten feeling serif" seen in the Havanza reference  
— Weight: 400 italic  

#### Body / UI Font
**Lora** (Google Fonts, free)  
— Used for all paragraph text, nav links, button labels, descriptions  
— Feels warm and literary, not cold and tech-y  
— Weight: 400 regular, 500 medium  

#### Utility / Data Font
**Plus Jakarta Sans** (Google Fonts, free)  
— Used only for prices, dates, form labels, small metadata, room codes  
— Weight: 400–600  

**Typography Scale:**

| Style | Font | Size | Weight |
|---|---|---|---|
| Hero H1 | Playfair Display | 72–96px | 700 italic |
| H2 Section Title | Playfair Display | 48–56px | 700 |
| H3 Card Heading | Playfair Display | 28–32px | 600 |
| Script Label | Cormorant Upright | 22–26px | 400 italic |
| Body | Lora | 16–18px | 400 |
| Nav | Plus Jakarta Sans | 14px | 500 caps |
| Button | Plus Jakarta Sans | 14px | 600 |
| Price Tag | Plus Jakarta Sans | 20px | 700 |

### 5.4 Layout & Spacing Philosophy

- **Generous white space** (actually warm cream space) — content breathes
- **Asymmetric layouts** — not everything centered; images bleed off edges
- **Polaroid / postcard cards** — photography shown in slightly rotated, stacked card frames (exactly like the Havanza reference)
- **Grid-breaking hero images** — hero photos should feel cinematic, full-bleed or nearly full-bleed
- **Section dividers** — use italic script labels ("Serenity & Bliss", "Sparkling Views") as section entry openers, not just bold headings
- **Horizontal scrolling galleries** — on mobile, gallery rows scroll horizontally
- **Column overlaps** — text blocks that slightly overlap image containers
- Maximum content width: **1280px**, centered, with sections that bleed edge-to-edge on full-width backgrounds

### 5.5 Imagery Style
- **Photography mood:** Warm afternoon light, golden hour tones, lush greenery
- **Polaroid framing:** Key gallery images styled as stacked polaroid cards with slight rotation (2–5°)
- **Real hotel photography** should be used throughout — avoid generic stock
- **Subject mix:** Rooms, restaurant food, hotel exterior, lobby, guests relaxing, pool (if any), Silchar cityscape/environment
- **Photo treatment:** Slightly warm-toned color grading; no desaturated moody edits

### 5.6 Decorative Elements
- Small botanical SVG illustrations (palm leaf, sunflower, bird/kingfisher silhouette — matching Assam's natural imagery)
- Thin ornamental borders on cards (1px marigold or teal)
- Section entry lines — decorative horizontal rules in marigold
- Flying bird silhouettes used as spacers / accents (as seen in Havanza reference)
- Subtle dot-grid or grain texture overlays on cream backgrounds for richness
- Circular photo crops for team / staff headshots

## 9. Technical Specifications

### 9.1 Tech Stack (Recommended)
- **Framework:** Next.js 14 (React) — for SEO, performance, and static generation
- **Styling:** Tailwind CSS + custom CSS for animations
- **Fonts:** Google Fonts (Playfair Display, Cormorant Upright, Lora, Plus Jakarta Sans)
- **Animations:** Framer Motion for scroll-triggered reveals, card hovers
- **Image optimization:** Next.js `<Image>` component with WebP auto-conversion
- **Forms:** Formspree (no backend needed) or React Hook Form + Email.js
- **Hosting:** Vercel (free tier, auto-deploys)
- **Domain:** luxuriagrandsilchar.com (or similar — to be registered)

### 9.2 Alternatively (Simpler Stack)
- HTML5 + CSS3 + Vanilla JS (or GSAP for animations)
- Hosted on Netlify or cPanel shared hosting

### 9.3 Performance Targets
- PageSpeed Insights score: 85+ (mobile), 95+ (desktop)
- First Contentful Paint: < 1.5s
- All images compressed and lazy-loaded
- No autoplay video on load (too slow for Indian mobile networks)

### 9.4 Browser Support
- Chrome, Safari, Firefox, Edge — latest 2 versions
- Mobile: iOS Safari 15+, Android Chrome 100+

### 9.5 Responsive Breakpoints
| Breakpoint | Width | Layout |
|---|---|---|
| Mobile | 0–767px | Single column, stacked |
| Tablet | 768–1023px | 2 columns where applicable |
| Desktop | 1024–1279px | Full multi-column |
| Wide | 1280px+ | Max-width container centered |

## 10. Animation & Motion Language

- **Page Load:** Staggered fade-up reveals on hero text (H1 words fade in one by one)
- **Scroll Triggers:** Sections slide up into view as user scrolls (not jarring — subtle, 0.4s ease)
- **Polaroid Cards:** On hover, card lifts slightly (translateY -6px) with soft box-shadow increase
- **CTA Buttons:** Marigold background animates to slightly darker shade on hover; slight right-arrow icon shift
- **Gallery Hover:** Teal overlay with photo title fades in
- **Navigation:** Smooth underline slide animation on nav links
- **Mobile Menu:** Smooth slide-down panel in Tobacco Brown

**Principle:** Motion should feel like the pages are breathing and welcoming — not bouncing or flashy.
